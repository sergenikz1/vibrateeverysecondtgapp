# RuTV — неофициальный клиент Rutube для телевизоров

Android TV приложение (APK) для просмотра Rutube на телевизоре/приставке
с пульта. Реклама не проигрывается: клиент забирает из ответа Rutube только
адрес контентного HLS-потока и отдаёт его в ExoPlayer, рекламный слой
веб-плеера при этом вообще не задействован.

Проект живёт в каталоге `android/` и никак не связан с остальным содержимым
репозитория.

## Что умеет

- Главный экран в стиле Android TV (leanback): полки «Продолжить просмотр»,
  «Избранное», закреплённые каналы, «Новое на Rutube» с бесконечной подгрузкой.
- Поиск по видео, в том числе голосовой (кнопка микрофона на пульте).
- Карточка видео: описание, автор, просмотры, дата, другие ролики канала.
- Плеер на Media3/ExoPlayer: HLS и прямые эфиры, перемотка стрелками ±10 c,
  play/pause центральной кнопкой, продолжение с места остановки.
- Избранное, история просмотра и закреплённые каналы — локально, без аккаунта.
- Настройки: ограничение качества (авто/360/480/720/1080), автопереход к
  следующему видео, очистка истории и избранного.

## Сборка

### Через GitHub Actions (ничего ставить не нужно)

Workflow `.github/workflows/android.yml` собирает APK на каждый push в
каталог `android/`. Готовый файл лежит в артефактах запуска (`RuTV-apk`):
**Actions → нужный запуск → Artifacts**.

Запустить вручную: **Actions → Build Android TV APK → Run workflow**. При
ручном запуске APK дополнительно публикуется в предрелиз `apk-latest` —
это запасной путь на случай, когда в аккаунте кончилась квота на артефакты
Actions (тогда шаг с артефактом падает, но сборку не валит).

### Локально

Нужен JDK 17 и Android SDK (`ANDROID_HOME`), сеть до `dl.google.com` и
Maven Central:

```bash
cd android
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

Без секретов сборка подписывается отладочным ключом — APK устанавливается,
но обновить его позже релизным ключом уже не получится (только переустановка).

### Подпись релизным ключом

Создайте ключ и положите его в секреты репозитория:

```bash
keytool -genkey -v -keystore release.jks -keyalg RSA -keysize 2048 \
  -validity 10000 -alias rutv
base64 -w0 release.jks   # значение для секрета RUTV_KEYSTORE_BASE64
```

Секреты: `RUTV_KEYSTORE_BASE64`, `RUTV_KEYSTORE_PASSWORD`, `RUTV_KEY_ALIAS`,
`RUTV_KEY_PASSWORD`. При локальной сборке те же значения задаются
переменными окружения (`RUTV_KEYSTORE_FILE` вместо base64).

## Установка на телевизор

1. Скачайте APK из артефактов сборки.
2. Включите на ТВ установку из неизвестных источников.
3. Поставьте любым способом:
   - `adb connect <ip-телевизора>:5555 && adb install -r RuTV-*.apk`
   - или через файловый менеджер / «Send files to TV» с флешки.
4. Приложение появится в списке приложений Android TV (и в обычном лаунчере —
   `leanback` помечен как необязательный, поэтому ставится и на приставки
   без Android TV).

Требования: Android 5.0+ (minSdk 21).

## Структура

```
android/app/src/main/java/org/rutv/client/
├── data/        RutubeApi (JSON-API), Repository, модели, локальное хранилище
├── ui/          главный экран, поиск, карточка видео, канал, настройки
├── player/      PlayerActivity на Media3/ExoPlayer
└── util/        форматирование длительности, просмотров, дат
```

Все сетевые адреса собраны в одном файле — `data/RutubeApi.kt`. Если Rutube
поменяет endpoint, правится только он:

| Что | Запрос |
| --- | --- |
| Лента | `GET /api/video/?page=N` |
| Поиск | `GET /api/search/video/?query=…&page=N` |
| Видео канала | `GET /api/video/person/{id}/?page=N` |
| Карточка видео | `GET /api/video/{id}/` |
| Поток | `GET /api/play/options/{id}/?format=json&no_404=true&pver=v2` |

## Ограничения

- Нет входа в аккаунт: подписки Rutube недоступны, вместо них — локально
  закреплённые каналы. Видео с возрастным ограничением, требующие авторизации,
  не откроются.
- API у Rutube неофициальное и без гарантий обратной совместимости.
- Приложение неофициальное и не связано с Rutube; товарные знаки принадлежат
  их правообладателям.
